Why the taxonomy is versioned

The same Korean label denotes a different class across taxonomy versions, so old episodes can be relabelled but not reinterpreted; the converter refuses them by schema version.

The training server never participates in an online path. The MCP server is dashed because it does not exist yet \u2014 the rule is currently read from a table shipped with the checkpoint.

Where the slow part ends and the fast part begins

The deliberative half is the classifier plus the rule that turns its answer into a destination; the reactive half is the policy and the executor.

The policy has its own vision-language encoder, but it is not a second deliberative system: this implementation emits actions and has no language-generation path, so the encoder grounds the sentence rather than deciding anything.

Collection-to-inference contract

Four hand-offs, each one a place where two sides can silently disagree.

A mismatch at these boundaries raises no error — the robot still moves, just wrongly.

Policy observation

Two RGB images, seven raw state values, and the rendered prompt string.

HIK RGB + ZED RGB + [j1…j6 deg, gripper] + prompt
→

16 × 7 action chunk

Six per-frame joint deltas in degrees; gripper absolute at index 6.

[Δj1, Δj2, Δj3, Δj4, Δj5, Δj6, gripper_abs]

Three failure modes that produce motion instead of errors

  • Pre-normalizing the state — the policy already applies norm_stats internally.
  • Rescaling the output — the returned chunk is already de-normalized.
  • Reading the gripper from the wrong index — there is no dummy seventh joint here.

Chunk integration

Anchor per chunk, accumulate open-loop, re-anchor at the next. How many of the sixteen steps run before re-inferring is not settled — E6 used eight, giving 2 Hz policy refresh against 16 Hz commands.

Prompt contract

The prompt string is an interface, so it is hashed.

Training and inference import the same renderer; a single differing character changes the token sequence.

Sequence budget

Two image slots512256 patches per slot
Prompt field200Padded; 12–34 measured
Action suffix16Equal to the action horizon
Total728Unchanged by prompt wording

A configuration flag adds a discretised state block worth 30–44 tokens with no visible symptom, so it is part of the hash.

What the hash covers

A digest over template, vocabularies, rig layout, and tokenizer settings; the robot recomputes it at startup and reports which field moved.

The category-to-shelf assignment is excluded; the waypoint-to-side layout is included, because a left/right flip is otherwise undetectable.

Label grounding

The destination is in the prompt, and that is the problem.

A prompt that names the shelf lets the policy arrive by copying a word; that measures manipulation, not grounding.

Why the signs need their own camera

Two separate things: the letters must survive tokenization, and they must be visible while the arm is in the way.

Experiment design

Every way to succeed without reading, and what closes it.

Each shortcut below produces the same success rate on a careless training set. The design is a list of things deliberately decorrelated.

ShortcutWhat closes it
Go where this category always wentThe assignment is permuted between episodes
Go to the holder of that colourHolders never move; only the label cards are swapped
Recognise which strip image this isFour layouts, so the cyclic order of the words is not constant
Read the cover instead of the promptEach physical book is labelled with each category in turn
Memorise this handwritingTwo typefaces trained, a third held out

Why four layouts and not three

Every balanced three-layout split holds the cyclic order of the words constant, which collapses reading into recognising one of three strip images.

Four layouts break it, at the price of a 2:1 skew — and the held-out layouts are exactly where that skew is wrong.

Three books, nine labellings

One book per category makes the cover a perfect substitute for the category word. Relabelling the same three books in a Latin square is cheaper than buying more, and stronger.

Physical bookRound 1Round 2Round 3

Two rounds would leave each book covering only two categories. The rounds must be interleaved within every cell, not assigned to whole cells.

Why 216 and not 240

TotalPer cellEach labelling per cellPer layout × labelling
21627 = 9 × 3exactly 3exactly 6
24030 = 9 × 3 + 33 – 46 – 8
28836 = 9 × 4exactly 4exactly 8

216 divides into three complete cycles of nine in every cell, which removes the deviation and the bookkeeping — and is twenty-four fewer episodes than 240, for a better design.

Six layout changes and one typeface change over the whole collection. The held-out layouts are never set up at all.

Reporting only ④ makes a failure unreadable — three explanations fit equally. ② and ③ separate them.

The strongest evidence needs no robot: change only the category word and see whether the predicted chunk turns a different way. A successful insertion is equally consistent with having memorised the scene.

Measured case · joint wrap

One wrapped frame in 540 raised that joint's delta standard deviation to 15.5 against 0.06–0.45 and took training loss from 0.13 to 2,386. Percentiles cannot absorb a 0.19% tail. The shortest-path correction restored 0.237 and normal loss.

The correction is a repair, not a resolution — a wrap means the joint reached its rotational limit during the demonstration.

Tooling

Something that refuses to ship, and something that can tell whether the prompt mattered.

A contract that is only written down is a convention.

Bundle export

It gathers weights, statistics and contract, recomputes the hash from the configuration about to be deployed, and refuses rather than emitting a bundle whose parts disagree.

Six refusal paths, including a stale tokenizer block that would still pass the hash, and a change in slot count that silently alters sequence length.

Prompt-sensitivity discriminator

Loss cannot separate a policy that reads the instruction from one that memorised a route. The discriminator fixes the observation, varies only the category, and compares between-prompt spread against within-prompt sampling noise.

Now run against trained policies. It asks how much the action moved; the destination question needed how it moved.
